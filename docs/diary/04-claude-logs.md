# Chapter 4: Reading Claude's clues

*Posted Wednesday, October 14, 2026, at 5:08 PM*

![Three cards for the bottom bar, the event notes and the conversation log, feeding one set of meters](heroes/04-claude-logs.png)

Claude Code offers three ways to watch it without changing it:
the bar along the bottom of its screen,
a short note it can send each time something happens,
and its log of every conversation.

The notes carry the text of your messages,
everything Claude read and wrote, and its replies.
skindeep keeps only plain facts, such as the kind of event,
which tool was used and how long it took,
and drops the rest.

When Claude's memory gets close to full,
Claude Code squeezes the older part of the conversation into a short summary,
and the memory gauge shows how close that squeeze is.
skindeep finds that point with the same rule,
read straight out of Claude Code's own program.
With a memory of one million units of text and no special settings,
the squeeze comes at 967,000.

One mistake ignored you.
You can tell Claude Code to squeeze at a different point,
but with the bottom bar turned off, the gauge never noticed,
and a window set to 400,000 drew the line as if it were set to 200,000.
Now the rule lives in one place and reads every way you can set it.

# Chapter 1: Drawing the map first

*Posted Wednesday, October 14, 2026, at 4:07 PM*

![Three boxes joined by arrows, the real program, the window and a second window, over thirty small numbered cards](heroes/01-design.png)

Welcome to the dev diary of skindeep.
The name is a backronym, a phrase built backward to fit a word:
"Skindeep Knickknacks, Instruments, and Needles,
Delivering Essentially Equivalent Performance."

If you used Winamp, you remember skins,
which left the music player the same underneath
but dressed it up as almost anything.
skindeep does the same for Claude Code and Codex on Linux,
two programs that write code with you in a terminal,
by running the real program, untouched,
inside a window full of live gauges, needles and lamps.
I wanted a gauge showing how much of the conversation
Claude can still hold in mind, and what a session has cost.

The plan starts with promises.
The window shows exactly what the program prints,
and the app never types into it, never keeps your passwords,
and never sends a message on its own.
A thin bar across the top, which no skin may hide,
always says what is really running.

This chapter holds no working program, only the plan:
a design document and thirty short decisions,
each stating the problem, what was picked, why,
and what was turned down.
The complete window comes together in chapter 14.

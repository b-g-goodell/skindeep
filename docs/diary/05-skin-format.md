# Chapter 5: A skin is just data

*Posted Wednesday, October 14, 2026, at 5:28 PM*

![An open folder holding the layout, images, fonts and style, stamped REFUSED because a file is missing](heroes/05-skin-format.png)

A skin is a folder of one layout file, some pictures,
some fonts and a sheet of style rules,
and it is not allowed to run any code.
The app runs next to your logins and your code,
and a skin is something you might download from a total stranger,
so a skin gets to paint and nothing else.

A terminal has to stretch whenever you resize the window,
so you place each piece by its distance from the edges.

A checker looks at every skin before it loads
and refuses a bad one at launch, naming the file and the entry at fault.
It makes sure every file the skin mentions really exists
inside the skin's own folder,
that the terminal stays at least 40 letters wide and 10 rows tall,
and that the text stands out from its background.

Editing a skin and choosing it again should show your change,
but the page kept the old style rules in its memory.
A test painted a skin purple, changed the file to green,
and picked the skin again, and it stayed purple.
Now every skin file is sent with a note that says "don't keep a copy."

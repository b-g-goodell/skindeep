# Chapter 23: Chalk, and a shorter front page

*Posted Wednesday, October 14, 2026, at 11:42 PM*

![Nine font names on a chalkboard with one circled, beside the front page shrinking from 3,022 words to 1,638](heroes/23-chalk-and-readme.png)

The library skin's chalkboard used a font called Gochi Hand,
and I thought it looked too much like Comic Sans.
So nine other handwriting fonts, all free to use,
were each tried out on the board and lined up in one picture.
I picked Fredericka the Great,
whose hollow capitals look like a hand-lettered sign on a chalkboard.

I also looked into a website called npmx.
It reports on the ready-made parts skindeep is built from,
such as how big they are and whether any has a known security hole.
It found none, but it missed the biggest part, the window engine,
so it stays something to read, not a tool that skindeep runs.

The front page had grown to 3,022 words,
and I cut it to 1,638, keeping every command you type
and moving the detail into the design notes, with a link to each.
The big picture at the top was taken again on the newest version.

With this chapter the project reaches version 0.2.0, its second release,
with fifteen visualizer modes, tabs that pop out into their own windows,
and the usage limits that say when they reset.

That's all twenty-three chapters, and thanks for following along.

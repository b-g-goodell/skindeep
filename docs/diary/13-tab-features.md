# Chapter 13: Seven small things, and a vanishing window

*Posted Wednesday, October 14, 2026, at 8:22 PM*

![The sessions dashboard, with three graphs and a row for each of two conversations](heroes/13-tab-features.png)

This chapter adds seven pieces,
each the brains of a feature the window will show next time.

The first remembers the last skin you used,
and if two windows picked different skins within five seconds,
skindeep asks which one you meant.
The second is the visualizer's window, which never steals focus,
and the third is a New tab... dialog
that shows the exact command the tab will run and lets you edit it.
The fourth is a watch-only tab for a conversation started somewhere else.

The fifth is the sessions dashboard above,
whose first math stretched the first few seconds to fill a whole minute,
so one quick burst at the start was drawn up to twelve times too big.

The sixth reads each project's issue board,
using the same login your Claude Code already has.

The seventh began when I chose an old conversation running in the background,
and the window vanished.
Claude Code won't open one while its command carries skindeep's extra settings,
so it printed how to open the conversation and quit,
and the window closed, taking that message with it.
Now skindeep runs that other command in the tab,
or leaves the message in your terminal.

# Chapter 15: A library and a coffee shop

*Posted Wednesday, October 14, 2026, at 8:53 PM*

![The library's shelf of books and lit lamp above the coffee shop's chalkboard, corkboard and lava lamp](heroes/15-library-and-coffee.png)

I asked for two more skins:
a library, and a coffee shop with quiet sounds.

The library has oak paneling, a shelf of book spines and a brass dial,
and a green banker's lamp lights up while Claude works.
It has no sounds, because a library is supposed to be quiet.

The coffee shop took two tries.
The first version was a neat cafe counter,
where an espresso machine's pressure gauge showed how fast Claude was writing,
but I didn't like its sounds, and it looked too much like a tidy chain cafe.
So I asked for a bohemian, counter-culture coffee shop instead.

The second version is an old brick basement cafe,
where string lights flare each time Claude uses a tool,
a lava lamp glows while Claude works,
and a record spins on a turntable while the terminal prints.

The new sounds are real recordings, given away free on freesound.org.
A small crowd talks quietly,
and now and then you hear a mug set down, a typewriter,
someone trying out the bongos, or the last notes of an acoustic guitar.
The guitar is the only tune, so it plays just once every four to ten minutes.

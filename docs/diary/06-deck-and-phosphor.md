# Chapter 6: Two skins, deck and phosphor

*Posted Wednesday, October 14, 2026, at 5:49 PM*

![The deck skin's instruments above the phosphor skin's radar sweep, lamps and dials](heroes/06-deck-and-phosphor.png)

The first two real skins both use the format from last time
and show the same readings.

deck is a dark brushed-metal face,
in the spirit of the desktop music players from the Winamp days,
and its numbers glow green in a seven-segment font.
A round gauge shows how full Claude's memory is,
a needle shows how fast Claude is writing,
and a knob shows how hard the processor is working.
Little lamps light up when Claude is busy, uses a tool,
or sends off a helper.

phosphor is an old green-screen console
with a radar sweep that turns while Claude works,
and everything glows in a font made to look like an old terminal.

Every font and picture needed a license that lets anyone share it.
A test reads a list of where each one came from, who made it and its license,
and fails on any file not on the list.

Needles move on a spring,
so they swing and settle instead of jumping from number to number.
One slow frame could throw the spring off and make the readouts run wild,
so now the spring takes tiny steps, 240 of them every second.
